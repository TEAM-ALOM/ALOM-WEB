당신은 트렌디하고 인터랙티브한 웹 디자인에 능숙한 시니어 프론트엔드 개발자입니다.
아래의 요구사항과 구조를 바탕으로 대학교 소프트웨어 개발 동아리 '아롬(AROM)'의 랜딩 페이지를 작성해 주세요.
Javascript는 절대 사용하지 말고, 오직 **순수 HTML과 CSS(최신 기능 포함)**만을 사용하여 구현해야 합니다.

# [핵심 요구사항]

1. 테마: 다크 모드 (배경은 딥 다크 블랙 #0a0a0a 또는 #111111, 텍스트는 밝은 화이트/그레이 사용)
2. 반응형: 모바일, 태블릿, 데스크톱 화면에 맞춰 자연스럽게 변하는 반응형 웹 (Media Query 사용)
3. 애니메이션: 순수 CSS만을 이용한 스크롤 애니메이션 구현 (`position: sticky`, `background-attachment: fixed`를 활용한 패럴랙스 효과나 최신 CSS `animation-timeline: scroll()` 활용)
4. 레퍼런스 스타일: https://www.bigdataboaz.com/ 와 같이 텍스트가 큼직하게 배치되고, 스크롤을 내릴 때 화면이 전환되거나 글씨가 이동하는 동적인 느낌을 주어야 함.

# [페이지 섹션별 상세 구조]

## 1. GNB (Global Navigation Bar)

- 화면 최상단에 `position: fixed`로 고정 (스크롤 시 배경색이 약간 투명한 검은색 베젤로 변하도록 블러 효과 적용)
- 좌측: 동아리 이름 'AROM' 로고 (텍스트 굵고 깔끔하게)
- 우측 네비게이션 메뉴: 커리큘럼, 아카이브, 자주 묻는 질문
- 메뉴에 마우스를 올렸을 때(hover) 부드러운 밑줄 애니메이션 추가

## 2. 메인 히어로 섹션 (Hero Section)

- 높이: `100vh`
- 정중앙에 시선을 사로잡는 큰 폰트 크기로 동아리 소개 텍스트 배치
- 예시 텍스트: "함께 성장하는 소프트웨어 개발 동아리, 아롬"
- CSS Keyframes를 사용하여 페이지 로드 시 텍스트가 아래에서 위로 부드럽게 나타나는(Fade-in & TranslateY) 효과 적용

## 3. 커리큘럼 섹션 (Curriculum)

- 스크롤 시 좌우 또는 사선에서 콘텐츠가 미끄러져 들어오는 애니메이션 효과 적용
- 2026학년도 2학기 개설 과목을 '주니어반'과 '시니어반' 두 개의 명확한 그룹으로 나누어 모던한 카드형 UI로 디자인
- 주니어반 항목: C언어 기초, 고급 C언어, 파이썬 기초 코딩, 알고리즘
- 시니어반 항목: Java, Spring, 프론트 기초(HTML,CSS,JS), React, AI - ML, AI - DL, 팀 프로젝트반
- 두 반의 성격이 시각적으로 대비되거나, 호버(Hover) 시 각 과목이 강조되는 입체적인 효과 추가

## 4. 동아리 활동 섹션 (Activities)

- 총 5가지 핵심 활동을 그리드(Grid) 레이아웃으로 배치
- 항목: 짝선짝후, 멘토멘티, 스터디, 세미나, 대회활동
- 각 카드 위에 마우스를 올렸을 때(Hover) 카드가 살짝 위로 떠오르며 테두리에 은은한 네온 빛(Glow)이 생기는 효과 적용

## 5. 리뷰 섹션 (Reviews)

- 동아리 부원들의 생생한 후기를 보여주는 섹션
- CSS `overflow-x: auto`와 `scroll-snap` 속성을 활용해 자바스크립트 없이도 가로로 스와이프/스크롤할 수 있는 캐러셀(Carousel) 형태의 카드 슬라이더 구현
