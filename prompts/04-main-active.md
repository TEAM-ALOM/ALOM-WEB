현재 ALOM 동아리 웹페이지의 '활동(Activities)' 섹션을 구현 중이야. 첨부한 레퍼런스 이미지(image_f7f618.jpg)처럼 사용자가 스크롤을 내림에 따라 좌측의 텍스트와 우측의 이미지가 동적으로 상호작용하는 고급스러운 UI를 만들고 싶어.

오직 순수 HTML, CSS, Vanilla JS만 사용해서 아래 요구사항에 맞게 코드를 작성해 줘.

# [핵심 레이아웃 및 디자인]

1. 전체 구조 (2단 레이아웃)
   - 부모 컨테이너는 Flexbox 또는 Grid를 사용하여 좌우 4:6 또는 5:5 비율로 나눈다.
   - 좌측(텍스트 영역): 동아리 활동 리스트(짝선짝후, 멘토멘티, 스터디, 세미나, 대회활동)가 세로로 길게 나열되어 스크롤된다. 각 항목 사이에 충분한 여백(margin/padding)을 두어 스크롤 시 한 항목씩 집중될 수 있게 한다.
   - 우측(이미지 영역): CSS `position: sticky`와 `top` 속성을 사용하여 화면 우측에 고정시킨다. 좌측 텍스트가 스크롤되어도 우측 컨테이너는 뷰포트 내에 머무르며 사진만 교체되어야 한다.
2. 테마: 다크 모드 (배경은 딥 다크, 텍스트는 화이트/그레이 계열)

# [동적 인터랙션 (JavaScript & CSS)]

1. 텍스트 하이라이트 (Intersection Observer API)
   - JS의 `IntersectionObserver` API를 활용하여 좌측의 각 활동 텍스트 요소가 화면의 중앙(특정 threshold 및 rootMargin 적용)에 도달했는지 감지한다.
   - 활성화된 항목 (화면 중앙): 텍스트 색상이 밝은 흰색으로 변하고 글씨가 강조되며, 숨겨져 있던 '세부 설명 텍스트'가 부드럽게 펼쳐진다(CSS height 및 opacity 트랜지션 활용).
   - 비활성화된 항목: 텍스트 투명도가 낮아져(opacity: 0.3 등) 어둡게 보이고, 세부 설명은 접혀서 보이지 않는다.
2. 이미지 크로스페이드(Crossfade) 교체
   - 활성화된 텍스트 항목의 `data-index` 또는 `id` 값을 바탕으로, 우측 고정 영역의 이미지를 그에 맞는 사진으로 변경한다.
   - 이미지가 바뀔 때 딱딱하게 뚝뚝 끊기며 바뀌지 않도록, 두 개의 이미지 태그나 배경 이미지를 겹쳐두고 CSS `transition: opacity`를 활용해 이전 이미지가 서서히 사라지고 새 이미지가 나타나는 부드러운 페이드 인/아웃 효과를 완벽하게 구현해야 한다.

# [출력 형태]

- HTML 뼈대: 각 텍스트 리스트와 우측 고정 이미지 컨테이너, data- 속성 포함.
- CSS 스타일: sticky 레이아웃 세팅, 활성화(.active) 클래스에 따른 텍스트 및 높이 전환 애니메이션, 이미지 크로스페이드 스타일.
- JavaScript: Intersection Observer 세팅 및 스크롤 시 텍스트 클래스 토글, 우측 이미지 교체 로직.
