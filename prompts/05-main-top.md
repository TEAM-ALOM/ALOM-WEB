현재 작성된 웹페이지의 상단 네비게이션 바(GNB) 영역의 코드를 수정해 줘.

# [수정 요구사항]

1. GNB 메뉴 항목 및 순서 변경
   - 기존 메뉴 구조를 변경하여, 우측 메뉴 항목들이 정확히 다음 순서대로 배치되도록 HTML 코드를 수정해 줘.
   - 변경된 순서: [ 커리큘럼, 아카이브, 아롬인들, 자주 묻는 질문 ]
   - 좌측에는 기존처럼 'ALOM' 로고가 위치해야 해. (첨부된 image_6c8b3c.png의 레이아웃 참고)

2. 동적 스크롤 기능 연동 유지 (JavaScript)
   - 새롭게 추가된 '아롬인들' 메뉴를 클릭했을 때도 기존 메뉴들과 동일하게, 해당 섹션(예: 후기 또는 부원 소개 섹션)으로 부드럽게 이동(Smooth Scroll)하도록 기존 `index.js`의 이벤트 리스너 로직이 잘 적용되는지 확인하고 필요한 HTML `id` 속성이나 JS 코드를 업데이트해 줘.

3. 디자인 및 스타일 유지 (CSS)
   - 메뉴 간의 간격, Hover 시 밑줄 애니메이션, 그리고 스크롤을 내렸을 때 GNB 배경이 반투명해지는 기존의 스타일링이 새로 추가된 메뉴에도 동일하고 자연스럽게 적용되도록 CSS를 점검해 줘.

위 요구사항을 반영하여 수정된 GNB 영역의 HTML 코드와, 필요한 경우 업데이트된 CSS/JS 코드 스니펫을 제공해 줘.
