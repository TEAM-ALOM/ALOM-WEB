1. 동아리 이름 수정: 모든 텍스트와 로고의 영문명을 'AROM'에서 'ALOM'으로 변경해 주세요.
2. 모던 자바스크립트: ES6+ 문법을 사용하고, 코드는 가독성 좋게 모듈화하거나 기능별로 주석을 달아주세요.
3. DOM 제어 및 이벤트 리스너: 바닐라 자바스크립트(Vanilla JS)만을 사용해 구현해 주세요.

# [JS로 구현할 상세 기능]

## 1. GNB 네비게이션 스무스 스크롤 (Smooth Scroll)

- 상단 네비게이션 바(GNB)의 메뉴(커리큘럼, 동아리 활동, 리뷰 등)를 클릭하면, 다른 페이지로 딱딱하게 넘어가는 대신 해당 섹션 위치로 부드럽게 스크롤 되도록 구현해 주세요.
- CSS의 `scroll-behavior: smooth`를 활용하거나 JS의 `scrollIntoView()` 메서드를 사용해 주세요.
- 헤더(GNB)가 `position: fixed`로 고정되어 있으므로, 스크롤 이동 시 헤더 높이만큼 콘텐츠가 가려지지 않도록 오프셋(Offset)을 계산해서 스크롤 되게 해주세요.

## 2. 동적 스크롤 애니메이션 (Intersection Observer API)

- 기존에 순수 CSS로만 구현하려 했던 스크롤 등장 효과를 JS의 `IntersectionObserver`를 사용하여 더 정교하게 만들어 주세요.
- 사용자가 화면을 스크롤하여 특정 섹션(커리큘럼 카드, 동아리 활동 그리드 등)이 화면(Viewport)에 일정 비율 이상 나타날 때, CSS 클래스(예: `.is-visible`)를 추가하여 애니메이션이 작동하도록 구현해 주세요.
- 스크롤을 위로 다시 올렸을 때 애니메이션을 초기화할지, 아니면 한 번만 실행할지(Once) 설정할 수 있도록 코드를 작성해 주세요.

## 3. 동적 GNB 스타일 변경

- 맨 위 최상단에 있을 때는 GNB 배경이 투명하다가, 스크롤을 조금이라도 내리면 GNB에 반투명한 배경색(블러 효과 포함)과 그림자가 생기도록 스크롤 이벤트 리스너를 추가해 주세요.

## 4. 리뷰 섹션 마우스 드래그 스크롤 (선택적 구현)

- CSS `scroll-snap`으로 만든 가로 스크롤 리뷰 섹션에 JS를 추가하여, 마우스 드래그(Click & Drag)로도 좌우로 스와이프할 수 있는 기능을 추가해 주세요.
